AI 设定

聊天用哪个 AI
拿 DeepSeek key：
  1. 打开 platform.deepseek.com，用 email 或 Google 注册
  2. 左边 Top up 充值（最少几美元，可以用卡或 PayPal）
  3. 左边 API keys → Create new API key，复制贴到这里
DeepSeek 用不了的时候，会自动改用 Gemini 回你（Gemini key 也要填）。
拿豆包 key：
  1. 打开 console.byteplus.com/ark，注册并登录
  2. 左边菜单 Model activation：开通 Dola-Seed-2.1-turbo（新用户有免费额度）
  3. 左边菜单 API keys → Create API key，复制贴到上面
  4. 模型 ID 照开通页面显示的填，例如 dola-seed-2-1-turbo-260628
建议在后台打开「只用免费额度」（Free tokens only），避免超额扣钱。
免费拿 key：
  1. 打开 aistudio.google.com/apikey，用 Google 账号登录
  2. 按 Create API key，复制贴到这里
key 只存在你的手机里。免费额度的聊天内容可能会被 Google 用来改进产品，别聊太隐私的事。
按「测试 key」后会自动选好能用的模型。
